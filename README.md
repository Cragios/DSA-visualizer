# DSA Visualizer

A React and TypeScript app for visualizing common sorting algorithms.

## Features

- Bubble Sort visualization
- Insertion Sort visualization
- Quick Sort visualization
- Adjustable array length
- Randomized array generation

## Getting Started

Requires Node.js 22 or newer and npm.

```bash
npm install
npm run dev
```

Open the local address shown by Vite.

## Available Scripts

```bash
npm run dev      # Start the development server
npm test         # Run tests
npm run lint     # Run ESLint
npm run build    # Create a production build
npm run preview  # Preview the production build
```

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Vitest

## Future Additions

- Additional sorting algorithms
- Data structure visualizations, including linked lists, stacks, queues, trees, and graphs
- Search algorithm visualizations

## Deployment

The app uses GitHub Actions to deploy to GitHub Pages whenever changes are pushed to `main`.

In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.

The live app is available at:

https://cragios.github.io/DSA-visualizer/
